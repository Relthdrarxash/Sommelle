Politique de confidentialité

Dernière mise à jour : 27 octobre 2026.

En bref : Sommelle ne collecte aucune donnée. Tout ce que vous saisissez reste sur votre téléphone. Il n'y a ni compte, ni serveur, ni publicité, ni outil de mesure d'audience.

Ce que l'application enregistre

Pour fonctionner, Sommelle enregistre sur votre téléphone, et uniquement sur votre téléphone :

  • vos réponses au questionnaire de départ (tranche d'âge et questions de sécurité) ;
  • votre agenda du sommeil (heures de coucher et de lever, estimations de la nuit, qualité ressentie) ;
  • vos horaires de sommeil calculés chaque semaine et votre heure de lever.

Ces informations concernent votre santé. C'est précisément pour cette raison qu'elles ne quittent jamais votre téléphone du fait de Sommelle.

Ce que nous recevons

Rien. Sommelle n'a pas la permission d'accéder à Internet : elle ne peut techniquement rien envoyer. Personne, pas même l'auteur de l'application, n'a accès à vos données.

Sauvegarde de votre téléphone

Les données de Sommelle sont exclues de la sauvegarde Android : elles ne sont jamais copiées dans votre compte Google.

Vous pouvez en revanche les faire passer d'un téléphone à l'autre, à votre initiative. Lors de la configuration d'un nouveau téléphone Android (version 12 ou plus récente), vous pouvez copier vos applications et leurs données directement depuis l'ancien, par câble ou sans fil : si vous ne le souhaitez pas, décochez Sommelle pendant le transfert. Vous pouvez aussi exporter votre agenda en CSV depuis l'appli, choisir vous-même où enregistrer le fichier, puis le réimporter dans les réglages du nouveau téléphone. Ce fichier est un simple CSV, lisible par quiconque l'ouvre : rangez-le comme un document de santé.

Effacer vos données

Dans les réglages de Sommelle, « Effacer toutes mes données » supprime tout de votre téléphone. Désinstaller Sommelle efface aussi toutes ses données.

Le site de Sommelle

Ce site est hébergé par GitHub Pages. Il n'utilise ni cookie, ni outil de mesure d'audience. Comme tout hébergeur, GitHub peut enregistrer des journaux techniques de connexion (adresse IP, date, heure, page demandée).

Vos droits

Comme aucune donnée personnelle n'est collectée par l'auteur de Sommelle, il n'y a pas de données à consulter, rectifier ou supprimer de notre côté. Pour toute question, vous pouvez écrire à pilmil.studio@proton.me.

Code ouvert

Le code de Sommelle est public et libre : chacun peut vérifier ce qui précède en le lisant sur GitHub.

Si vous traversez un moment difficile, le 3114 est joignable gratuitement, jour et nuit.
